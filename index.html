1

SEED — Start the Movement

Continuous · monthly Owner: per-BU sponsors Output: onboarded cohort

What you do

  • Sign up (and share the sign-up form with your BU) to join the next Agent Boss cohort.
  • Establish cadence and regular touchpoints with the cohort.
  • Agree on success criteria you'll track through the program.

What you walk away with

  • A seat in the ASEAN Agent Boss community (Teams).
  • A defined success rubric for your cohort.
  • Your starting build path (no-code → low-code → pro-code).
2

LEARN — Prove It Fast

1–3 months Owner: Agent Boss + Coach Output: working prototype

What you do

  • Run a Solution Envisioning workshop on a shared board.
  • Prototype with the right build path (CoWork → Studio → Foundry).
  • Pilot with 3–5 people from your own BU; diagnose patterns.

What you walk away with

  • A high-impact use case with measurable KPIs.
  • A working agent prototype validated by real users.
  • Pattern fixes applied — ready to harden in PACKAGE.
Open the Playbook Pathfinder → Run a Solutioning board →
3

PACKAGE — Make It Repeatable

3–5 months Owner: Agent Boss + Eng partner Output: registry-ready package

What you do

  • Observe usage; compare deltas and impact on the target metric.
  • Standardize the agent: templates, configs, run-books, docs.
  • Pass the production / repeatability gate with the engineering partner.

What you walk away with

  • A standardized, well-documented agent package.
  • Proof a new team can run the agent without the original builders.
  • A submission ready for the ASEAN Skill Registry.
4

SCALE — Multiply Impact

5–7 months Owner: Coaches + Program leadership Output: production + customer-ready

What you do

  • Coach adoption across new cohorts and BUs.
  • Define which agents are external-ready / customer-ready.
  • Publish to the Agent Registry and expand production footprint.

Targets (per deck)

  • 1 production agent in every ASEAN division (11 total).
  • 3 customer-referenceable agents.
  • MAU target: 10% of org actively using agents.

Graduate as an Agent Boss

Agents that survive PACKAGE earn their builder a Bachelor; agents that scale through SCALE earn a Master.

After Phase 3

BSc — Bachelor Agent Boss

An agent with real usage, packaged and repeatable beyond its original team.

After Phase 4

MSc — Master Agent Boss

An agent in production with sustained usage and measurable business impact.
